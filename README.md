# 问道

生辰取名、公司起名。先看四柱，再按五行缺补、音律、字义和《康熙字典》笔画给出名字，并写明每个字的寓意、依据和备注。

这份代码在私密仓库 [xisoz/wendao](https://github.com/xisoz/wendao)。仓库主人是 xisoz，只有你能看、能改。别人不能把它拿去发布。

Grok 里的预览地址是临时通道，会断，不能拿来给客户用，也不能拿来收费。要自己赚钱，用这份仓库部署到你自己的服务器和域名上。

```bash
npm install
npm run dev
```

正式构建：

```bash
npm install
npm run build
```
